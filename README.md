## Features

- **Live prices** — BTC, LTC, ETH, SOL, USDT, converted from EUR / USD at checkout
- **Automatic verification** — payments are checked on-chain
- **Instant delivery** — text, keys or files by DM as soon as the payment confirms
- **Sticky "Buy" dropdown** — always at the bottom of the shop channel
- **Multi-seller** — every seller gets their own channel and stock
- **Non-custodial** — funds go straight to the seller's wallet
- **Owner-controlled** — the server owner decides who can manage and sell

## How it works

1. Add the bot to your server
2. `/setup` — private log channel
3. `/register_shop` — turn a channel into a seller's shop
4. `/wallets` — seller sets payout addresses
5. `/add_product` — list a product with price and delivery

Buyers pick a product, get the exact live amount by DM, pay and paste the TXID.
The bot verifies on-chain and delivers.
